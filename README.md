# Paper & Pace website

Public static website for Paper & Pace, hosted on GitHub Pages.

Edit `products.json` to update product cards and checkout links, then run `python build.py` and commit the generated HTML. Colours and bundled fonts follow `brand.yaml` from the Pinforge repository. Font licenses are in `assets/fonts/`.

The site intentionally has no analytics, cookies, or contact form. Policy pages should be reviewed when business or checkout practices change.
